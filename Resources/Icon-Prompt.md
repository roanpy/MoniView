# App icon

Generated using the built-in imagegen tool, then resized into macOS iconset sizes and packaged as `MoniView.icns`. The original PNG is `AppIcon.png`.

## Prompt

Use case: logo-brand. Asset type: production macOS app icon for MoniView, a simple HDMI capture-card viewer. Create one square 1024x1024 icon, a centered dark warm charcoal squircle with smooth Apple-style rounded corners, occupies about 82% of canvas with genuinely transparent outside. In its center, one bold amber orange line symbol combining a minimal rounded monitor outline and four viewfinder corner brackets, generous negative space. Flat geometric, extremely simple, crisp and legible at 32 pixels, slightly warm orange gradient on the symbol, subtle elegant bevel on dark tile only. Front-on icon asset, no mockup, no text or letters, no white background, no extra objects, no watermark, no dramatic glow.
