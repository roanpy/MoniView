# Screenshots

The READMEs reference actual screenshots of MoniView connected to a Jemdo Video capture card. Captions must describe the visible state accurately; no screenshot may contain fabricated values.

- `moniview-window.png`: live preview with the brief source status line.
- `moniview-controls.png`: capture settings with aligned controls.

Before committing a screenshot, remove capture card serial numbers, device identifiers, private file paths, usernames, and any diagnostic text that should not be public. Because these images are referenced by both README.md and README.zh-CN.md, add the real files here rather than linking to an external host.
