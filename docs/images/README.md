# Screenshots

The READMEs reference two screenshots. Both must be captured from the actual MoniView app running against a real capture card, and neither may contain a fabricated value.

- `moniview-window.png` for the preview window with the brief status line visible.
- `moniview-controls.png` for the open control panels.

Before committing a screenshot, remove capture card serial numbers, device identifiers, private file paths, usernames, and any diagnostic text that should not be public. Because these images are referenced by both README.md and README.zh-CN.md, add the real files here rather than linking to an external host.
